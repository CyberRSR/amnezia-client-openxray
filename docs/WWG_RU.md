# WWG на Android

WWG — цепочка из двух туннелей AmneziaWG v2:

```text
Android-приложение -> входной AWG v2 netstack -> локальный UDP relay -> выходной AWG v2 -> интернет
```

Входной туннель использует официальный Go netstack AmneziaWG и не создаёт интерфейс Android `VpnService`. Он открывает UDP relay на loopback. Выходной туннель единолично создаёт системный VPN-интерфейс и подключает peer через этот relay. Физические сокеты входного туннеля защищаются вызовом `VpnService.protect`, чтобы они не зацикливались через выходной VPN.

## Импорт и сохранённый профиль

Сначала выберите входной `.conf` AmneziaWG, затем выходной. В обоих файлах должны быть `protocol_version=2` и обязательные параметры AWG v2 J/S/H/I. Другие версии и неполные профили отклоняются до запуска соединения.

Схема сохранённого контейнера:

```text
containers[].container = "amnezia-wwg"
containers[].wwg.underlay_awg = AwgProtocolConfig
containers[].wwg.overlay_awg  = AwgProtocolConfig
```

Android runtime получает:

```text
runtime.protocol = "WWG"
runtime.awg_underlay_config_data = <клиентский конфиг входного слоя>
runtime.awg_overlay_config_data  = <клиентский конфиг выходного слоя>
```

Portable export/import `.vpn` сериализует оба слоя без преобразования в один нативный `.conf`.

## Жизненный цикл и восстановление

Вся цепочка принадлежит одной coroutine, защищённой mutex и generation counter. Перезапуск всегда закрывает `overlay -> relay -> underlay`, затем запускает `underlay -> relay -> overlay`. Во время восстановления состояние остаётся `RECONNECTING`; параллельный worker или второй relay запустить невозможно.

Relay проверяется каждую секунду. Раз в пять секунд выполняется HTTP-проба через Android network с явным `TRANSPORT_VPN`; предусмотрен резервный URL. Фатальная ошибка relay вызывает немедленный restart, два последовательных неуспешных HTTP-раунда — полный restart цепочки. Временная ошибка запуска повторяется через пять секунд, затем каждые десять секунд без ограничения попыток. Ручное отключение отменяет monitor/restart jobs и закрывает все handles. Ошибки формата при первом запуске остаются фатальными.

## Безопасность

Репозиторий, APK и релизы не должны содержать реальные серверные профили, приватные ключи, PSK, SSH-данные и IP развёртывания. Конфиги развёртывания следует хранить во временном защищённом каталоге, а серверные файлы — с правами `0600`.
